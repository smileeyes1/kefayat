# Source Registry

Raw curriculum material must be stored separately from normalized competency records.

## Provenance states

- `USER-PROVIDED REFERENCE`: supplied by the user; usable as the working reference, not automatically official.
- `OFFICIAL VERIFIED SOURCE`: independently verified against an authoritative publication.
- `INFERENCE`: derived interpretation; never treated as source text.
- `UNPROVEN`: insufficient evidence.

## Integrity rule
Never rewrite, shorten, merge, or silently correct source text in the raw layer.

## Current repository state
The repository was initially empty. Exact historical competency text is not present in the current GitHub tree, so this layer intentionally contains no invented competency content. Historical source recovery must use the actual supplied files/messages or a verified source before population.
