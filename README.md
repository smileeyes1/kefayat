# KEFAYAT / GEM Ω

## Evidence-Governed Competency-to-Lesson System

This repository is the implementation baseline for a Grade 1–4 educational system built around the user's competency working baseline and MASTER Ω assurance architecture.

### Mission
Transform curriculum source material into traceable, verifiable educational outputs:

`SOURCE → COMPETENCY → LEARNING OUTCOME → OBSERVABLE PERFORMANCE → ACTIVITY → EVIDENCE → ASSESSMENT → ASSURANCE → RELEASE`

### Scope
- Grades 1–4
- Arabic
- Mathematics
- Islamic Education
- Nurturing / civic-life competencies
- Exact source preservation
- Separate normalization layer
- Stable IDs and traceability
- Grade progression and coverage audits
- Lesson and assessment generation
- MASTER Ω assurance gates
- Mathematical visual-order and graphics-count safeguards
- Islamic authenticity safeguards

### Evidence posture
User-provided competency material is treated as `USER-PROVIDED REFERENCE` unless independently verified. The application must never silently promote user-provided content to `OFFICIAL VERIFIED SOURCE`.

### Engineering rule
The deterministic knowledge and assurance layers are authoritative. AI is an assistive generation layer and is not itself the curriculum oracle.

### Status
Architecture bootstrap. The repository starts empty and is being populated incrementally through evidence-governed commits. No system-wide or universal assurance is claimed from repository existence.
