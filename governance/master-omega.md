# MASTER Ω Integration Contract

Baseline: `MASTER Ω vΩ.7.4 + OAC-01 + OAG-01`

Status: FROZEN. This file integrates the existing assurance baseline into the application; it does not redefine or upgrade the baseline.

## Mandatory execution chain

`UNDERSTAND → EXTRACT → INTEGRITY → FREEZE → EVIDENCE PLAN → RISK → PLAN → EXECUTE → VERIFY → BREAK → REPAIR → REVERIFY → REGRESSION → EVIDENCE AUDIT → INDEPENDENCE → CLAIM-SCOPE → DECIDE → RELEASE`

## Educational traceability

`SOURCE → COMPETENCY → LEARNING OUTCOME → OBSERVABLE PERFORMANCE → ACTIVITY → EVIDENCE → ASSESSMENT`

## Non-negotiable controls

1. No evidence → no claim.
2. User-provided material is not labeled officially verified without independent evidence.
3. Original source text is immutable; normalization is a separate layer.
4. Every generated lesson must have a traceable competency path.
5. Critical failures are NO-GO.
6. Missing evidence is NOT PROVEN or BLOCKED, not an invented success.
7. Repairs require reverification and regression.
8. Mathematical visual order is explicit and never delegated to RTL/BiDi/renderer behavior.
9. Numeric graphics require `VALUE → REQUIRED COUNT → VISUAL GROUP → ACTUAL COUNT → EVIDENCE`.
10. Total correctness does not prove subgroup correctness.
11. Pilot success does not prove system-wide or universal validity.
12. Evidence state cannot escalate without its transition criteria.
13. Claims must not exceed evidence scope.
14. MASTER Ω may audit internal consistency but cannot serve as evidence of its own external independence.

## Subject-specific assurance

### Islamic Education
Use an independent authenticity gate for Qur'an, hadith, attribution, interpretation, and age appropriateness. Unverified religious attribution must not be presented as established fact.

### Mathematics
Represent mathematical expressions as structured data with an explicit visual order. Visual counting must be checked against the actual artifact, not metadata or labels.

## Release posture

`RELEASE UNDER CLAIM SCOPE` is the default successful release posture. `UNIVERSAL`, `GLOBAL`, and `SYSTEM-WIDE` claims require evidence specifically supporting those scopes.
